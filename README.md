# ISX Pulse
## The Heartbeat of Iraqi Markets

**Version**: 0.1.0-alpha.4 | **Status**: Alpha Development | **Release**: October 10, 2025

A professional Go-based analytics platform for real-time monitoring, processing, and analysis of Iraq Stock Exchange (ISX) trading data, featuring a modern Next.js dashboard with advanced charting and enterprise-grade security.

## Overview

This application provides automated data collection and processing for ISX trading data, featuring:
- **Advanced Charting**: TradingView Lightweight Charts v5.0.8 with professional price chart visualization
- **Market Overview Page**: Real-time market visualization with Iraqi calendar-aware trading date picker (Friday-Saturday weekends), market treemap, and index charts
- **Enhanced Tooltips**: Daily comparisons, performance metrics, and smart positioning
- **Intelligent Auto-Detection**: Automatically selects optimal processing mode based on existing file coverage
- **Smart Defaults**: Uses January 1st to today date range when no dates specified
- **Automated Excel Downloads**: Collects ISX daily reports with browser automation
- **Data Transformation**: Converts Excel files to structured CSV format
- **Real-time WebSocket Updates**: Live progress monitoring in web dashboard
- **Hardware-based License**: Secure activation with device fingerprinting
- **Modern React/Next.js Frontend**: TypeScript-based dashboard with Tailwind CSS and Zustand state management
- **Enterprise Observability**: Structured logging and OpenTelemetry integration
- **Comprehensive Testing**: Unit test suites ensuring data processing reliability

## Architecture

### Backend (Go)
- **Web Server**: Chi router v5 with embedded frontend
- **Operations System**: Multi-step concurrent data processing
- **WebSocket**: Real-time updates using Gorilla WebSocket
- **License Management**: Hardware fingerprinting and activation
- **Observability**: Structured logging (slog) and OpenTelemetry

### Frontend (Next.js)
- **Framework**: Next.js 14 with TypeScript
- **UI Components**: Shadcn/ui with Tailwind CSS
- **Real-time Updates**: WebSocket integration
- **Static Export**: Embedded in Go binary

### Executables
- `ISXPulse.exe`: Main analytics server with embedded dashboard (port 8080)
- `ISXScraper.exe`: Automated ISX report downloader
- `ISXProcessor.exe`: Data transformation and CSV export engine
- `ISXIndexer.exe`: Market index extractor (ISX60/ISX15)
- `activate-license.exe`: License activation tool

## Quick Start

### Prerequisites
- Go 1.23.0+ (verified with `.go-version`)
- Node.js 18.17.0+ (verified with `.nvmrc`)
- Python 3.8+ (optional, for backtesting support)
- Windows OS (for production builds)

### Building

```bash
# Complete build (backend + frontend)
./build.bat        # Windows

# Development
cd api
go mod tidy
go test ./... -race
```

### Cleanup (Lean Workspace)

The following paths are safe to delete locally and will be regenerated by builds/installs as needed:

- `web/node_modules/`, `web/.next/`, `web/out/`, `web/coverage/`, `web/.swc/`
- `web/tsconfig.tsbuildinfo`
- `api/cmd/web-licensed/frontend/` (embedded frontend build output; required for building/testing `api/cmd/web-licensed`)
- `logs/` and `api/logs/`
- `dist/` build outputs (keep `dist/license.dat` if you need an installed license)

### Running with Automatic Mode Detection

ISX Pulse features intelligent automatic mode detection that simplifies data collection.
If `dist/*.exe` is missing, run `./build.bat` first.

```bash
# Start ISX Pulse server
./dist/ISXPulse.exe

# Simplified data collection - automatically detects optimal mode
./dist/ISXScraper.exe
# Defaults: January 1st of current year to today, auto-detects accumulative/initial

# With custom date range
./dist/ISXScraper.exe -from 2025-06-01 -to 2025-08-24

# Process collected data
./dist/ISXProcessor.exe

# Extract market indices
./dist/ISXIndexer.exe
```

#### Automatic Mode Detection Logic

The system uses a simplified binary decision approach for reliability:

- **Accumulative Mode**: Files exist - downloads missing files and ensures latest data is collected
- **Initial Mode**: No files exist - fresh download of all data for the specified range

No manual mode selection required - the system always attempts to get the latest data, ensuring you never miss market updates.

### Example: System in Action

```bash
# First run - empty downloads directory
./dist/ISXScraper.exe
# Output: Mode auto-detected: initial (no files found)
# Downloads all files from Jan 1, 2025 to today

# Second run - files exist
./dist/ISXScraper.exe
# Output: Mode auto-detected: accumulative (143 files found)
# Downloads missing files and ensures latest data is collected

# Partial data scenario
./dist/ISXScraper.exe -from 2025-06-01 -to 2025-08-24
# Output: Mode auto-detected: accumulative (87 files found)
# Downloads only missing files and gets latest data
```
